### 👨‍💻 Sobre Mim

Olá! Sou o **Leonardo Nascimento** 👋, graduando em **Análise e Desenvolvimento de Sistemas** pelo Centro Universitário Cesmac e desenvolvedor focado em criar soluções completas (**Backend & Full Stack**).

Sou movido por resolver problemas reais através de **código limpo, arquitetura escalável e automação**. No meu dia a dia, concentro-me na construção de APIs RESTful de alta performance, modelagem de bancos de dados relacionais consistentes e interfaces web e mobile modernas e intuitivas.

- 🎯 **Foco atual:** Arquitetura de APIs assíncronas com **FastAPI**, ecossistema **React / React Native** e conteinerização com **Docker**.
- 🏗️ **Especialidades:** Sistemas de gestão (SaaS/ERP/PDV), integrações de serviços, automação de processos e modelagem SQL.
